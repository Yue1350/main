Privacy Policy

This Privacy Policy explains how TTS Bot (hereinafter referred to as "the Bot") handles user data and information when providing text-to-speech and voice channel services.

1. Information We Process

The Bot temporarily processes minimal data necessary to function properly:

  • User Identifiers: Discord User IDs and Display Names (used for voice channel join/leave announcements and identifying message authors).
  • Server & Channel Identifiers: Discord Guild IDs and Channel IDs (used to save server-specific configurations like preferred voice, playback speed, and designated reading channels).
  • Message Contents: Text messages sent in designated channels (processed temporarily to generate speech audio via Google Cloud TTS).

2. Data Retention & Storage

  • Temporary Audio Files: Audio files (`.mp3`) generated for TTS playback are automatically deleted immediately after playing.
  • Server Settings: Guild preferences (voice type, speed, channel configurations) are stored in memory while the Bot is running and reset upon restart unless permanently logged.
  • No Message Logging: Chat messages are processed in real-time and are never permanently stored on external databases or log files.

3. Third-Party Services

The Bot interacts with the following third-party APIs to provide its core services:

  • Google Cloud Text-to-Speech API: Text input is sent securely to Google Cloud TTS to generate voice audio. No personal identifiers are attached to these requests.
  • Discord API: Used to read messages, manage voice connections, and handle Webhooks for custom emoji processing.

4. Data Protection & Security

We do not sell, trade, or share any user data with third parties. Authentication keys and API credentials are kept securely environment-restricted.

5. Changes to This Policy

This Privacy Policy may be updated periodically. Any changes will be posted on this page with an updated effective date.
